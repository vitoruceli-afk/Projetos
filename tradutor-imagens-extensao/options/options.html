Tradução

OCR

O reconhecimento de texto roda sempre no seu computador (Tesseract.js). Nenhuma imagem é enviada para servidores para fazer OCR.

Idiomas de reconhecimento
Idiomas marcados como “não instalado” precisam do arquivo lang/<código>.traineddata na pasta da extensão. Veja o README.

Visual

A tradução sobreposta cobre cada linha original e escreve a tradução na mesma posição, com o tamanho da fonte ajustado à largura do texto original. Alinhamento e cores são aproximados.

Desempenho

As imagens só são processadas quando você pede. Nada roda em segundo plano enquanto a extensão está ociosa. O mecanismo de OCR é liberado da memória após 1 minuto sem uso.

Histórico

    Privacidade

    OCR local
    Sempre no seu computador. A imagem não sai do navegador para o reconhecimento de texto.
    Tradução
    Enviado para o provedor escolhido: somente o texto reconhecido (ou o texto da página, na tradução de página inteira). A imagem não é enviada para a tradução. Com LibreTranslate ou um serviço próprio, os dados vão para o servidor que você configurar.
    APIs externas
    Google Cloud Translation, LibreTranslate ou o serviço personalizado, somente quando você configura um deles.
    Armazenamento local
    Configurações, chave de API e histórico ficam em chrome.storage.local, neste navegador. Miniaturas do histórico são pequenas. Nada é sincronizado com a conta Google.
    Permissões
    A extensão não tem acesso permanente a todos os sites. Ela só atua na aba em que você usa um comando, o menu de contexto ou o ícone (permissão activeTab).
